# Aashika-Portfolio
Personal portfolio website showcasing my skills, projects, education, and web development experience.
## Overview

This is my personal portfolio website developed using HTML, CSS, and JavaScript. 
It showcases my profile as a BCA student, my technical skills, academic background, projects, and professional contact links.

The website is responsive and designed to provide a clean, modern, and user-friendly experience across different devices.

## Features

- Responsive navigation bar with mobile menu
- Hero section with personal introduction
- Social media links for GitHub, LinkedIn, and Email
- Downloadable CV
- About Me section
- Technical Skills section
- Featured Projects section
- Education timeline
- Contact section
